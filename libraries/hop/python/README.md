# codefly-hop (Python)

The authority hop's stamp, authenticated by a module served in Python. The Go
library (`../go`, `hop.Verifier`) is the same contract; both read the fixture the
Go hop writes (`../testdata/stamped.json`, regenerated by the Go test with
`-update-fixture`).

```python
from authority_client._gen.host.authority.v1.authority_pb2_grpc import AuthorityServiceStub
from codefly_hop import Unauthenticated, Verifier

verifier = Verifier(AuthorityServiceStub(channel), audience=os.environ["CODEFLY__MODULE"], proof=proof)  # once, at startup
identity = verifier.verify(request.headers)  # raises Unauthenticated, naming why
identity.tenant, identity.owner, identity.has("documents.collection", "read")
identity.claims.allows("documents.collection", "write", collection_id)
```

`channel` reaches the authority the module already depends on (the interface
`codefly.dev/authority`): the local authority on a laptop, the host on a cell.
The verifier checks the stamp first, then reads the published keys through `Keys`
on a thread of its own with a 5 s timeout, one read at a time; it re-reads them
when a token names a key it does not hold (at most every 10 s) and when they are
older than 5 minutes; keys that cannot be re-read are trusted for 15 minutes at
most. It never fails to construct on an authority that is not serving yet, and
refuses calls with a fixed reason until it is; `verifier.keys_error` holds the
read's own failure for logs.

`verify` authenticates the token (`authority_client.work_context.authenticate`:
proof, digest, issuer, Ed25519 signature, audience, window), reads who the call
is for from the authenticated claims, and refuses a stamp that says otherwise.
`identity.advisory` is the hop's warning-mode reason; it grants nothing.

A module depends on it by its git coordinates at a pinned commit:
`codefly-hop @ git+https://github.com/codefly-dev/authority@<commit>#subdirectory=libraries/hop/python`.
Install it with uv: its `authority-client` dependency is a path source to the
sibling library, so uv resolves it at the same commit; no second pin or
override is needed. (pip does not read `tool.uv.sources`.)

```sh
uv run --with pytest --with-editable . pytest
```
